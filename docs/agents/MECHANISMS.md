# BTC 5m Mechanism Registry

Flow stage: LEARN/OBSERVE. Scope: LIVE remains BTC 5-minute Up/Down
only. PAPER/SHADOW scope partially lifted by OP-REPLICATION-SCOUT-PAPER
(operator Béla + Fable, 2026-07-19): paper-only scouting of adjacent
short-cycle up/down markets (eth-5m first) is authorized within idle
lane capacity, pre-registered, never displacing BTC5M lanes. Scout
scope = the crypto short-cycle family that OP-BTC5M-EXCLUSIVE itself
names "alongside" (ETH/crypto updown series); beyond-crypto replication
stays gated by the 4-green-week release in AUTONOMOUS_FLOW. Any live
path outside BTC-5m still requires the full standard gates plus a
separate Fable ruling.

This registry is the canonical catalog of paper mechanisms to run in
parallel. Paper breadth is free information; live graduation remains
disciplined and must pass the unchanged wallet-copy / CopyIntent evidence
gate before the live guard can submit.

## Rules

- Every mechanism stays paper-only unless a Fable DIRECTION explicitly
  admits it through the standard live gate.
- Every new experiment/mechanism must be pre-registered before result
  inspection with `scripts/preregister_experiment.py`: hypothesis,
  success criterion, failure criterion, primary metric, measurement
  window, decision rule, deadline, owner, and result artifacts. The
  append-only registry is `data/research/experiment_preregistry.jsonl`;
  unregistered results cannot support promotion.
- Weekly R&D yield counts only gated findings: a result must pass its
  pre-registered criterion, or be recorded as a clean null/tombstone answer,
  before it counts as shipped yield. Activity alone is not yield.
- Yield pressure never bypasses adversarial-twin or holdout doctrine; every
  finding still needs the normal capital gate before it can affect live size,
  roster, or eligibility.
- Any campaign with running processes but zero shipped gated findings over
  seven days is STALLED until it produces an answer or is retired.
- All mechanisms write window evidence for their registered market scope
  (BTC5M by default; scout lanes their scouted series) and can share the
  same window matrix data layer.
- No mechanism waits for another mechanism. Morning review ranks every
  lane in one table by live-paper PnL, fill quality, participation, and
  repeatability.
- PARKED non-BTC5M knowledge may remain referenced, but it receives no lane
  work in this scope.
